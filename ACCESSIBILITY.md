# Accessibility Statement

We aim to make the GridWM-Judge research artifacts understandable and usable by as many people as reasonably possible. The project provides primarily **command-line research tools**, Markdown documentation, and scientific figures, rather than a conventional interactive application.

## Current practices

- Instructions, task definitions, and command-line examples are available as text in the [README](README.md).
- GitHub Issues and pull requests provide text-based channels for reporting problems or requesting clarification.
- The README overview illustration includes alternative text, and the accompanying [paper](https://arxiv.org/abs/2611.13596) explains the benchmark and its evaluation principles in prose.

## Known limitations

- Some overview diagrams, rendered simulator frames, and presentation assets contain visual details that may not be fully represented in alternative text.
- Certain benchmark tasks necessarily assess image understanding; an equivalent non-visual account of all experimental stimuli is not currently provided.
- The repository and its linked project site have **not** undergone a comprehensive accessibility audit or formal WCAG conformance assessment. We therefore do not claim full compliance with a specific accessibility standard.
- External services linked from this repository (such as model providers or dataset hosts) have their own accessibility practices.

## Feedback and assistance

If an installation instruction, data format, diagram, or published result is difficult to access, please open a [GitHub issue](https://github.com/xinyuw922-pixel/Towards-Reliable-VLM-Judge/issues/new/choose) with the affected page or file and the alternative format or explanation that would help. You may also contact **qinanzhang@mail.ustc.edu.cn**.

We welcome actionable suggestions and contributions such as better figure descriptions, clearer headings, readable tables, accessible documentation formats, and text summaries of key visual examples. Improvements will be considered as maintenance capacity allows.
